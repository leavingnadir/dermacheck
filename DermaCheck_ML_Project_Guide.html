DermaCheck — Group Project Step-by-Step Guide

IT2011 Artificial Intelligence and Machine Learning · Classical ML on the HAM10000 metadata CSV only (no images, no CNN)

Since your lecturer confirmed you should use the CSV metadata only (not the lesion images), you don't need a neural network. Your predictors will be age, sex, and localization (body site), and your target will be the dx column (7 diagnostic classes). This guide covers a full classical ML pipeline that satisfies every part of your Group Assignment Specification (Steps 1–5) using Python and Jupyter Notebook.
Set expectations early: age, sex, and body site alone are weak predictors of lesion type compared to the actual image. Don't expect high accuracy — the point of this assignment is to show a sound ML process (preprocessing, EDA, model comparison, honest evaluation), not to build a clinically accurate diagnostic tool. Say this explicitly in your report's limitations section — it's a strength, not a weakness, to acknowledge it.

4. Step 2 — Clean & preprocess the data

PREPROCESSING

This is where each of your 6 members can each "own" one technique (required for the Progress Review I individual marks).

  • Missing values — age has ~57 missing values. Impute with median age, or drop those rows. 
    df['age'] = df['age'].fillna(df['age'].median())
  • Duplicate lesions — some lesion_id values appear more than once (multiple images per lesion). Since you're not using images, decide whether to keep one row per lesion or keep all rows (documented decision either way). 
    print(df['lesion_id'].duplicated().sum())
df_unique = df.drop_duplicates(subset='lesion_id', keep='first')
  • Encoding categorical variables — sex and localization need encoding for ML models. 
    df = pd.get_dummies(df, columns=['sex', 'localization'], drop_first=True)
  • Outliers — check age for unrealistic values (e.g. 0) with a boxplot; cap or remove if needed.
  • Normalization/scaling — scale age so it doesn't dominate distance-based models like SVM. 
    from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
df['age_scaled'] = scaler.fit_transform(df[['age']])
  • Encode the target — turn dx into numeric labels for scikit-learn. 
    from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df['dx_encoded'] = le.fit_transform(df['dx'])
print(dict(zip(le.classes_, le.transform(le.classes_))))

Assign one technique above per member, each in their own notebook: notebooks/IT_Number_Preprocessing_technique.ipynb.

FEATURES

Build your final feature matrix X and target y:

feature_cols = ['age_scaled'] + [c for c in df.columns if c.startswith('sex_') or c.startswith('localization_')]
X = df[feature_cols]
y = df['dx_encoded']

Optional: add dx_type as a one-hot feature too if you want a richer feature set (be transparent that this is metadata about label confidence, not a clinical feature).

7. Step 5 — Handle class imbalance & split the data

SPLIT

Because ~67% of records are the NV class, a model can score high accuracy while never predicting melanoma. Use a stratified split and class weighting (or SMOTE) to counter this.

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)

# Option A: class_weight='balanced' inside the model (simplest, recommended)
# Option B: SMOTE oversampling on the training set only
from imblearn.over_sampling import SMOTE
sm = SMOTE(random_state=42, k_neighbors=3)
X_train_res, y_train_res = sm.fit_resample(X_train, y_train)
Only resample the training set — never the test set, or your evaluation will be misleadingly optimistic.

8. Step 6 — Build Model 1 (baseline)

MODEL 1 
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier

logreg = LogisticRegression(max_iter=1000, class_weight='balanced')
logreg.fit(X_train, y_train)

rf = RandomForestClassifier(n_estimators=300, class_weight='balanced', random_state=42)
rf.fit(X_train, y_train)

Justification to write in your report: Logistic Regression and Random Forest are fast, interpretable baselines that check whether age/sex/location alone carry any separable signal before trying anything more complex.

11. Step 9 — Evaluation & k-fold cross-validation

EVALUATION 
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.metrics import classification_report, confusion_matrix, f1_score
import matplotlib.pyplot as plt
import seaborn as sns

# Stratified k-fold cross-validation
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(rf, X, y, cv=skf, scoring='f1_macro')
print("Macro-F1 per fold:", scores)
print("Mean macro-F1:", scores.mean())

# Test set evaluation
y_pred = rf.predict(X_test)
print(classification_report(y_test, y_pred, target_names=le.classes_))

cm = confusion_matrix(y_test, y_pred)
sns.heatmap(cm, annot=True, fmt='d', xticklabels=le.classes_, yticklabels=le.classes_, cmap='Purples')
plt.xlabel("Predicted"); plt.ylabel("Actual")
plt.title("Confusion Matrix")
plt.show()

Report accuracy, macro-F1 (important given the imbalance), and per-class recall — especially recall on the malignant classes (mel, bcc, akiec), since missing those is the costliest error in a triage tool.

This satisfies Assignment Step 4 (30 marks).

12. Step 10 — Compare models & pick the best

COMPARISON 
results = {
    "Logistic Regression": f1_score(y_test, logreg.predict(X_test), average='macro'),

for name, score in sorted(results.items(), key=lambda x: -x[1]):
    print(f"{name}: {score:.3f}")

Build a small comparison table (Accuracy | Macro-F1 | Malignant-class recall) and justify the best performer in prose — this becomes your "Evaluation and Comparison" report section.

Also report a naive baseline: a model that always predicts "NV" gets ~67% accuracy but 0% recall on every malignant class. Your models should be judged against beating this baseline on macro-F1 and malignant recall — not raw accuracy.
